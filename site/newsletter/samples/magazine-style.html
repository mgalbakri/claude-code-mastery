What's New
New

Multi-File Edit Mode

Claude Code can now propose coordinated edits across multiple files in a single turn. This means refactoring a function and updating all its callers happens atomically.

→ Affects Week 7 (Refactoring) and Week 9 (Large Projects)
New

Hook Execution Now 3× Faster

Pre- and post-command hooks run in parallel where possible, cutting overhead from ~900ms to ~300ms on average. Your custom validation hooks will feel instant.

→ Affects Week 10 (Hooks & Automation)
Updated

Extended Thinking Defaults to On

Starting with Claude Opus 4.6, extended thinking is enabled by default for complex prompts. No more manually toggling it — the model decides when deep reasoning is needed.

→ Affects Week 6 (Prompt Engineering)
Heads Up

Legacy /config Command Removed

The /config slash command has been fully replaced by settings.json and CLAUDE.md. If your workflow still references /config, update to the new approach.

→ Affects Week 4 (Configuration)
Quick Tip of the Week

Chain Hooks for Pre-Commit Quality Gates

Combine the new parallel hooks with a pre-commit chain: run lint, type-check, and test in parallel before every commit. Here's the pattern:

// .claude/settings.json
{
  "hooks": {
    "pre-commit": [
      "npm run lint",
      "npm run typecheck",
      "npm run test:quick"
    ]
  }
}
