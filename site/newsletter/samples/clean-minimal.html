What Changed
New Feature

Multi-File Edit Mode

Claude Code now proposes coordinated edits across multiple files in a single turn. When you refactor a function, all its callers get updated atomically — no more hunting through files one by one.

Updated: Week 7 (Refactoring) · Week 9 (Large Projects)
New Feature

Hook Execution 3× Faster

Pre- and post-command hooks now run in parallel where possible, cutting average overhead from ~900ms to ~300ms. Custom validation hooks feel nearly instant.

Updated: Week 10 (Hooks & Automation)
Updated

Extended Thinking Defaults to On

With Claude Opus 4.6, extended thinking is now enabled by default for complex prompts. The model decides when deep reasoning is needed — no manual toggling required.

Updated: Week 6 (Prompt Engineering)
Deprecated

Legacy /config Command Removed

The /config slash command is gone, fully replaced by settings.json and CLAUDE.md. If your workflow still references it, now's the time to migrate.

Updated: Week 4 (Configuration)
Tip of the Week
Try This

Chain the new parallel hooks into a pre-commit quality gate — lint, type-check, and test all run simultaneously before every commit:

// .claude/settings.json
{
  "hooks": {
    "pre-commit": [
      "npm run lint",
      "npm run typecheck",
      "npm run test:quick"
    ]
  }
}
