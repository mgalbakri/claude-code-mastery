Essential Terminal Commands

Everything you need to navigate your filesystem and manage files from the command line.

Navigation

pwdPrint current directory
lsList files in directory
ls -laList all files with details
cd folderEnter a folder
cd ..Go up one level
cd ~Go to home directory
cd -Go to previous directory

Create & Copy

mkdir nameCreate a folder
mkdir -p a/b/cCreate nested folders
touch file.txtCreate an empty file
cp src destCopy a file
cp -r dir/ dest/Copy a directory

Move & Delete

mv old newMove or rename
rm fileDelete a file
rm -rf dir/Delete a directory

View & Search

cat filePrint file contents
head -20 fileFirst 20 lines
tail -20 fileLast 20 lines
grep "text" fileSearch in file
grep -r "text" .Search recursively
find . -name "*.ts"Find files by pattern

Pro tip: Press Tab to auto-complete file and folder names. Press Ctrl+R to search your command history.

Claude Code Prompt Patterns

Write better prompts to get better code. These patterns work in Claude Code and any AI coding tool.

Effective Prompts

  • Be specific: "Add a login form with email and password fields" not "add auth"
  • Provide context: "In the Express server at server.ts, add a GET /api/users endpoint"
  • State constraints: "Use only standard library, no external packages"
  • Ask for explanations: "Explain each step as you implement it"

Common Prompt Templates

  • New feature: "Create a [component] that [does X]. It should [constraints]."
  • Bug fix: "The [feature] is [broken behavior]. Expected: [correct behavior]. Fix it."
  • Refactor: "Refactor [file] to [pattern]. Keep the same behavior."
  • Tests: "Write tests for [function] covering [edge cases]."

Git Quick Reference

Version control essentials. Every command you need for daily Git workflow.

Setup & Init

git initInitialize a new repo
git clone urlClone a remote repo
git statusShow working tree status
git log --onelineCompact commit history

Stage & Commit

git add fileStage a specific file
git add .Stage all changes
git commit -m "msg"Commit with message
git diffShow unstaged changes
git diff --stagedShow staged changes

Branches

git branchList branches
git branch nameCreate new branch
git checkout nameSwitch to branch
git checkout -b nameCreate & switch
git merge nameMerge branch into current

Remote

git pushPush to remote
git pullPull from remote
git push -u origin mainSet upstream & push
git remote -vShow remotes

Undo & Fix

git restore fileDiscard changes
git restore --staged fUnstage a file
git stashStash changes
git stash popRestore stashed changes
git reset HEAD~1Undo last commit (keep files)

Pro tip: Use git commit -m "feat: description" with conventional commit prefixes: feat:, fix:, docs:, refactor:, test:

CLAUDE.md & MCP Quick Start

Configure Claude Code for your project and extend it with MCP servers.

CLAUDE.md Starter Template

# Project Name

## Tech Stack
- Language: TypeScript
- Framework: Next.js 16
- Database: Supabase (PostgreSQL)
- Styling: Tailwind CSS 4

## Conventions
- Use functional components with hooks
- Prefer named exports
- Tests live next to source files

## Commands
- `npm run dev` — start dev server
- `npm test` — run tests
- `npm run build` — production build

Where CLAUDE.md Files Go

~/CLAUDE.mdGlobal (all projects)
./CLAUDE.mdProject root (shared)
./.claude/CLAUDE.mdPersonal (gitignored)
./src/CLAUDE.mdDirectory-specific

MCP Server Basics

  • What: Plugins that give Claude new tools (database access, APIs, etc.)
  • Where: Configure in .claude/settings.json
  • How: claude mcp add name command

Common MCP Servers

filesystemRead/write files outside project
postgresQuery databases directly
githubPR reviews, issues, actions
playwrightBrowser automation & testing
